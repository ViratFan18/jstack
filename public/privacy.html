JSTACK / PRIVACY

Privacy Policy

Effective date: November 18, 2026

Tool inputs and theme preference

JWTs, keys, secrets, JSON, and text entered into JStack tools are processed in your browser and are not sent to a JStack application server or saved in local storage. JStack stores only your light or dark theme preference in local storage so it can be remembered across pages. Do not share production secrets with any website unless you have independently reviewed its code and deployment.

Hosting and technical requests

The site is designed for static hosting on Cloudflare Pages. The hosting provider may process technical request information such as IP address, user-agent, requested URL, and security events under its own terms and privacy practices. JStack does not operate a database or application backend.

Advertising, cookies, and consent

The site does not currently load advertising scripts or serve ads, and no analytics script is enabled. The public ads.txt file is a publisher declaration and does not itself load ads. If advertising or analytics is added later, this policy must be updated and any legally required consent controls configured before personal data or storage is used for advertising.

External services

The app does not load external fonts or make third-party API calls during normal tool use. Links to other websites are opened only when a visitor chooses them; those sites have their own policies.

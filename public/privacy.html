Privacy Policy

This page describes the current project configuration. It is not a statement about every hosting-provider practice or a substitute for jurisdiction-specific legal review.

Tool inputs and generated output

JWTs, keys, secrets, JSON, and text entered into JStack tools are processed by code running in your browser. The tool operations do not send those inputs to a JStack application backend. Inputs and generated results remain in page memory and are not intentionally saved to local storage. Closing or reloading the page can discard them. Do not use a shared device for sensitive material, and independently review the code and deployment before using real credentials.

Local browser preferences

When browser storage is available, JStack uses local storage for the selected theme and lists of recent and favorite tools. These preferences stay in that browser profile; they are not required to use the tools. If storage is blocked, the workspace remains usable, but preferences may not persist.

Feedback and email handoff

The feedback form prepares a mailto link on the device; the visitor must choose to open it, review the email draft, and send it. It does not submit data to a JStack server. If sent, the message is handled by the visitor's email provider and recipient's email system, whose processing and retention are outside this site.

Hosting and technical requests

The project is configured for static hosting. A hosting provider may process technical request information, such as IP address, user-agent, requested URL, and security events, under its own terms and privacy practices. The project does not include an application backend or database; this does not mean the hosting provider receives no request metadata.

Advertising, cookies, and consent

Indexable public pages load the Google AdSense library using the publisher ID configured for this site. This repository does not include manually placed ad-unit markup; whether ads are requested or displayed also depends on the publisher's AdSense settings, review status, and Google's systems. Google may process request, device, cookie, or advertising data under its own terms and privacy policies. JStack does not control Google's processing. The operator must configure any consent controls required for the site's audience and applicable law before enabling advertising features.

The root ads.txt file identifies an authorized seller; it does not itself place ads. No Google Analytics script is configured.

External services

JWT, JSON, Java-model, and text-conversion operations run in the current page and do not call a JStack application backend. Indexable public pages load the Google AdSense library; Google may make additional requests when its publisher settings enable advertising. JStack's tool inputs are not intentionally sent to that library by the tool code. The app uses locally hosted fonts. Links to other websites are opened only when a visitor chooses them; those sites have their own policies.

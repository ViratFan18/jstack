JSTACK / ABOUT

JWT and text tools for developers.

JStack brings common token and data-format tasks into one browser-based workspace.

JWT workbench

Inspect compact JWTs, sign and verify JWS tokens, and encrypt or decrypt supported JWE formats. Cryptographic operations use the browser and the maintained jose library. Decoding only reveals encoded content; it does not verify a token or authorize access.

JSON tools

Format, minify, and check the syntax of JSON. Syntax validation does not validate application schemas or business rules.

JSON to Java models

Generate nested Java records or POJOs from a sample JSON object. The generator infers types rather than validating a schema; null-only or mixed values use Object. Renamed JSON keys use Jackson @JsonProperty annotations.

Base64 text

Encode UTF-8 text to standard Base64 and decode standard Base64 back to text. Base64 is an encoding format, not encryption. Base64URL is a distinct format and is not accepted by this tool.

JStack Base128

JStack Base128 is a custom format that packs UTF-8 bytes into seven-bit groups and maps them to Braille symbols U+2801–U+2880. It is not a universal standard and is only compatible with decoders using the same mapping.

Local processing

Tool inputs are processed in the page and are not sent to a JStack application backend or saved in local storage. The hosting provider still receives ordinary web requests; see the Privacy Policy.

The tools are for convenience and education. Review security-sensitive results independently before production use.

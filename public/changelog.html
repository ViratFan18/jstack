Developer tool workspace

The current project includes JWT decode, JWS sign and verify, JWE encrypt and decrypt, key generation, JSON format/minify/syntax validation, JSON-to-Java model generation, standard Base64 text conversion, and the custom JStack Base128 converter.

Explore the workspace · Read tool limitations

Product discovery and navigation

The product homepage presents workflows and all 12 tools. The Ctrl+K command palette searches tools and informational pages, and can surface recent and favorite tools when browser storage is available. These lists are optional; no account is required.

Security and data-handling notes

Tool operations run in the browser and do not send inputs to a JStack application backend. JWT decoding is distinct from signature verification, verification is distinct from authorization, JSON validation is syntax-only, and Base64 is not encryption. See the Privacy Policy for browser preferences and hosting boundaries.

Learning and support pages

The Learning Center includes Java and backend examples for JWT handling, JSON-to-Java modeling, JWS/JWE decisions, and text encodings. Feedback prepares a mailto link for the visitor; there is no server-side submission or ticket system.
